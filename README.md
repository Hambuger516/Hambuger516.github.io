# Hanbo Ma · Academic website

Bilingual academic homepage hosted at https://Hambuger516.github.io/

Static HTML, CSS, and JavaScript. Open `index.html` locally, or serve this directory with `python3 -m http.server 8765`.

- `index.html`: bilingual homepage and publication filters
- `cv.html`: print-friendly academic CV
- `publications.bib`: publication metadata
- `.nojekyll`: serve as a static GitHub Pages site
